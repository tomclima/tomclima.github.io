#COMPSCI
Usado como uma camada de abstração entre aplicações java e sistemas de diretório. Permite abstrair objetos java para nomes
ex: ao invés de hard code as informações de conexão e localização de um banco de dados, é possível abstrair o banco como um objeto DataSource e relacionar o banco de dados específico com o nome "jdbc/meuBancoDeDados".
