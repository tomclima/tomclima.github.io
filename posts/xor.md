# definition
the `xor` operator is defined by the following properties:
- 1 xor 1 = 0
- 1 xor 0  = 1

## reversibilidade
além disso, é assiciativo e comutativo. Dessa forma, infere-se a seguinte propriedade:
```
a xor b = a' <-> a' xor b = a
```
ou seja, ele é reversível
